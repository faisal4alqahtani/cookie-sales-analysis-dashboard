\# Cookie Sales Analysis Dashboard



\## Project Overview



An interactive sales analysis dashboard built with Power BI to analyze cookie sales performance across products, retailers, and countries.



\## Dashboard



\![Cookie Sales Analysis Dashboard](dashboard.png)

\## Key Performance Indicators



\- Total Sales: 46.11K

\- Total Quantity: 18K

\- Number of Orders: 200

\- Number of Retailers: 20



\## Analysis



The dashboard provides insights into:



\- Sales performance by product

\- Sales performance by retailer

\- Sales performance by country

\- Sales trends over time

\- Top 10 retailers by sales

\- Interactive filtering by product and country



\## Tools \& Technologies



\- Power BI

\- Power Query

\- Microsoft Excel



\## Data Preparation



The data was imported from Excel and prepared for analysis using Power Query. Relationships were created between the retailer and order datasets to support interactive analysis.
